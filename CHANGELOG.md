# Changelog

This file tracks visible changes to the Magnexis Voice pilot; version numbers do not imply a fully deployed, audited production release.

## [1.25.0] — 2026-10-24

### Added
- Descriptive search titles, canonical URL and open graph/X metadata for the intended Netlify host.
- Schema.org WebSite and SoftwareApplication JSON-LD (correctly labeled as a pilot).
- `robots.txt` and four-URL `sitemap.xml`.
- Standalone, indexable About, How It Works and Datasets information pages.
- Desktop and mobile UI screenshot assets and social-sharing preview using a local UI smoke-test screenshot.
- SEO implementation and deployment verification guide.
- Desktop-app setup documentation and an opt-in Windows Electron installer CI build.

### Changed
- Application and desktop-window version labeling updated to 1.25.0.
- Homepage footer links to crawlable information pages.
- README extended with v1.25 screenshots and desktop usage guide.

### Still pending
- Verified Netlify production deployment, live upload/review testing, public-enrollment safeguards and signed Windows installer release.

## [0.1.0] — Initial pilot

- Persistent speech contributions, independent voting, curated sample archives, responsive UI, Electron shell and six API integration tests.
